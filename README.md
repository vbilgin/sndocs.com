# sndocs.com

A Python CLI that turns the [ServiceNow/ServiceNowDocs](https://github.com/ServiceNow/ServiceNowDocs)
Markdown corpus into a locally-served static docs site, built with MkDocs and
Material for MkDocs.

This repository holds code and config only. It does not house releases,
CI/CD automation, or generated output.

Nothing is implemented yet. See the issue tracker for the v1 spec.
